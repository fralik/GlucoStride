Choose by display size

Use the dedicated 16 px artwork at 16 px, the 24 px artwork at 24–32 px, and the master at 48 px and above. Avoid fractional CSS sizes and positions. PNG icon exports are 1x; SVGs scale with display density.

Use the correct colourway

Navy #101B24, mint #6EE7C2 and paper #F5F5EE. Use reverse or mint assets on navy; both retain the heavier reverse trail. Prefer the navy-backed mint logo for Markdown on unknown backgrounds.

Keep the files self-contained

Logo lettering is outlined: no installed fonts or external downloads are required. Project assets are local SVG and PNG files; Android uses native VectorDrawable XML for the launcher and notification icons.
